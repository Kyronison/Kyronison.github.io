Privacy Policy

Last updated: October 8, 2026

Who we are

Origins of Giants Pipeline is the internal production tool of the Origins of Giants YouTube channel. It is operated by the channel owner for the channel owner's own use.

What data the tool accesses

With the owner's consent through Google OAuth, the tool accesses the owner's own YouTube channel through the YouTube Data API and YouTube Analytics API in order to upload the channel's videos and Shorts, edit their metadata, thumbnails and schedules, post comments from the channel, and read the channel's own statistics.

The tool does not request, collect or store data about any other person. It has no public users and no public sign-in.

How data is stored

The OAuth access token is stored only on the owner's own computer and is used only to perform the actions above. Data is not sold, shared or transferred to third parties.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API Services are used in accordance with the YouTube Terms of Service and the Google Privacy Policy.
